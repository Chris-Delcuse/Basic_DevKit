📈 FnCheck
----------
- Find out available locations to 'Define' in all mode.

⌨️ Cmd Example:

    appfolder\FnCheck("PARAMETRIC")

📈 Fncheck_3D
-------------
- Find out available locations to 'Define' in graph mode 3D
- ( For packaged Apps )

📈 Fncheck_lite
---------------
- Find out available locations to 'Define' in graph mode FUNCTION
- ( For packaged Apps )

🔐 PwDGeN ( No GUI )
---------
- Powerful password generator.
- Format : Numeric, Digicode, Apha-Numeric & Special α-Numeric.

⌨️ Cmd Example :

    pwdgen("Alpha-Num",10)

✒️ Note: GUI is the best way to secure entries.
